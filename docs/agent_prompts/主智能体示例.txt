医生主智能体使用示例

重要说明：
1. 主智能体必须通过子智能体调用工具，不能直接调用工具！
2. 子智能体列表：pubmed_analysis_assistant、patient_management_assistant、case_library_assistant、care_plan_assistant、document_parsing_assistant
3. 患者管理工具使用 medical_record_no（病历号）而不是 patient_id
4. 病例库工具需要 tenant_id 参数
5. 康复计划工具需要 medical_record_no、tenant_id、user_id
6. PubMed日期格式必须用斜杠 YYYY/MM/DD，康复计划日期用横杠 YYYY-MM-DD
7. 代码必须使用 ```<RUN> 开头，```<END_CODE> 结尾，否则不会被执行！


====================
一、PubMed 文献检索（通过 pubmed_analysis_assistant）
====================

用户：检索近3个月前列腺癌免疫治疗的研究热点

思考：用户需要检索近3个月的前列腺癌免疫治疗文献。当前日期是2024/12/03，所以开始日期是2024/09/03。日期格式必须用斜杠。我需要通过 pubmed_analysis_assistant 来执行文献检索任务。

代码：
```<RUN>
result = pubmed_analysis_assistant(task="search_pubmed(advanced_search='prostate cancer AND immunotherapy', start_date='2024/09/03', end_date='2024/12/03', max_results=100, output_filename='prostate_immuno_3m.json')")
print(result)
```<END_CODE>

观察结果：检索成功，找到99篇文献，已保存到 prostate_immuno_3m.json

思考：检索成功，现在需要分析关键词热点。继续通过 pubmed_analysis_assistant 进行分析。

代码：
```<RUN>
analysis = pubmed_analysis_assistant(task="analyze_research_keywords(filename='prostate_immuno_3m.json', top_n=15, include_trends=True)")
print(analysis)
```<END_CODE>

观察结果：{"success":true,"top_keywords":[...]}

最终回答：近3个月前列腺癌免疫治疗研究共找到99篇文献，主要研究热点包括...

====================
参数格式速查表
====================

PubMed日期格式：YYYY/MM/DD（斜杠）
  正确：start_date='2024/09/01'
  错误：start_date='2024-09-01'

康复计划日期格式：YYYY-MM-DD（横杠）
  正确：start_date='2024-12-01'

症状列表格式：列表
  正确：symptoms=['咳嗽','胸痛','呼吸困难']
  错误：symptoms='咳嗽,胸痛'

患者管理：使用病历号
  正确：medical_record_no='P00000123'
  错误：patient_id=123

病例库和康复计划：需要tenant_id
  正确：tenant_id='default'

康复计划：需要user_id
  正确：user_id='doctor001'

文件路径：必须完整路径
  正确：image_url='/tmp/upload/doc.jpg'
  错误：image_url='doc.jpg'


====================
代码格式规范（重要！）
====================

正确格式（会被执行）：
  代码：
  ```<RUN>
  result = pubmed_analysis_assistant(task="search_pubmed(...)")
  print(result)
  ```<END_CODE>

错误格式（不会被执行）：
  代码：
  search_pubmed(...)
  
  或
  
  代码：
  ```python
  search_pubmed(...)
  ```


====================
子智能体调用规范（重要！）
====================

主智能体必须通过子智能体调用专业工具，不能直接调用！

正确方式：
  result = pubmed_analysis_assistant(task="search_pubmed(...)")
  result = patient_management_assistant(task="patient_management_get_patient_basic_info(...)")
  result = case_library_assistant(task="case_library_search_medical_cases(...)")
  result = care_plan_assistant(task="care_plan_create_care_plan(...)")
  result = document_parsing_assistant(task="document_parsing_detect_document_type(...)")

错误方式（会报 Forbidden function 错误）：
  search_pubmed(...)  # 直接调用工具会失败！
  patient_management_get_patient_basic_info(...)  # 直接调用会失败！
