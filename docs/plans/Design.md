# 安语 AI 医疗平台 — 功能总览与创新规划

> 日期: 2026-03-09

---

## 一、现有功能（已实现）

### 整体架构

三端入口：**医生端** · **患者端** · **管理端**

每个端口各有专属 AI 智能体、工具集和界面，共用聊天框架和后端服务。

---

### 医生端

#### 核心页面


| 页面    | 功能                           |
| ----- | ---------------------------- |
| 患者列表  | 搜索、筛选、创建患者，查看患者基本信息          |
| 患者详情  | 患者概览、诊疗时间线、康复计划、待办事项         |
| 诊疗时间线 | 按时间轴展示就诊记录、检验报告、影像报告、指标变化、附件 |
| 康复计划  | 用药方案、康复任务、注意事项、完成进度统计        |
| 病例库   | 搜索/创建/收藏病例，查看症状、检查结果、治疗方案    |
| 知识库   | 访问医学知识资源                     |
| 对话界面  | 与 AI 助手对话，可关联患者和时间线          |


#### 对话增强功能


| 功能    | 描述                              |
| ----- | ------------------------------- |
| 关联患者  | 对话可绑定患者，AI 自动获取患者上下文            |
| 关联时间线 | 对话可绑定诊疗阶段，保存的数据自动归入该阶段          |
| 对话状态  | 标记对话为进行中/待跟进/疑难病例/已完成/已归档       |
| 对话标签  | 自定义标签，便于分类检索                    |
| 对话摘要  | 编辑和保存对话摘要                       |
| 快捷指令  | `/` 触发常用指令面板（chatCommandPicker） |
| 对话模板  | 预设模板快速发起常见任务                    |


#### AI 智能体工具集（56 个 MCP 工具）


| 类别    | 工具数 | 主要能力                    |
| ----- | --- | ----------------------- |
| 患者管理  | 5   | 创建、更新、删除、搜索患者，重复检测      |
| 时间线管理 | 9   | 创建事件、保存详情、上传图片/附件、保存指标  |
| 报告管理  | 8   | 保存/查询/删除检验报告（含明细项）和影像报告 |
| 病例库管理 | 10  | 创建/更新病例、保存症状和检查结果、收藏管理  |
| 待办事项  | 3   | 创建/更新/删除患者待办任务          |
| 病例检索  | 5   | 按症状搜索相似病例、获取病例详情        |


---

### 患者端

#### 核心页面


| 页面   | 功能                         |
| ---- | -------------------------- |
| 个人档案 | 查看基本信息、诊断历史、检验/影像报告        |
| 康复计划 | 查看用药安排、康复任务、注意事项，记录服药/完成任务 |
| 对话界面 | 与 AI 健康助手对话                |


#### AI 智能体工具集


| 类别     | 工具数 | 主要能力                      |
| ------ | --- | ------------------------- |
| 患者信息查询 | 6   | 查询自己的基本信息、诊断、过敏史、病史、家族史   |
| 时间线查询  | 3   | 查看就诊事件、详情、指标数据            |
| 康复计划   | 6   | 查看计划、用药、任务、注意事项，记录服药和完成情况 |
| 患者查找   | 2   | 按病历号或邮箱定位患者               |


---

### 管理端


| 功能    | 描述                   |
| ----- | -------------------- |
| 智能体配置 | 为医生端/患者端分配和配置 AI 智能体 |
| 模型管理  | 配置 LLM 模型参数          |
| 知识库管理 | 上传和管理医学知识文档          |


---

### 后端服务


| 服务          | 描述                                     |
| ----------- | -------------------------------------- |
| AI Agent 框架 | 基于 Nexent SDK，支持多步推理、工具调用、流式输出         |
| 文件管理        | MinIO 对象存储，支持图片/PDF/文档上传下载             |
| OCR 服务      | PaddleOCR，支持从图片中提取文字                   |
| 对话管理        | 对话历史、多轮上下文、患者关联                        |
| 多租户         | 租户隔离，支持多机构部署                           |
| 数据库         | PostgreSQL（Supabase），ORM 基于 SQLAlchemy |

## 二、创新想法（待实现）

### 智能体交互创新


| #   | 想法          | 描述                                                      | 备注                     |
| --- | ----------- | ------------------------------------------------------- | ---------------------- |
| 1   | ⭐ 对话中的交互式卡片 | 智能体保存数据后，在聊天流中嵌入可操作的结构化卡片（查看/编辑/跳转），不只是纯文字回复            | —                      |
| 2   | 语音输入查房×     | 医生查房时语音输入，智能体实时转文字 + 自动识别要记录的内容（症状、医嘱、指标），自动归档到对应患者的时间线 | 需集成 ASR 服务             |
| 3   | ⭐ 智能体主动提醒   | 不只是被动问答。智能体定时扫描：过期未复查的患者、指标持续异常、用药快到期，主动推送提醒卡片          | 需后台定时任务 + 推送           |
| 4   | 多智能体协作      | 医生发一条消息，多个专科智能体并行分析（影像科AI、病理科AI、药学AI），各自给出意见后汇总         | 需要 agent 编排框架          |
| 5   | ⭐ 智能体记忆与学习  | 记住每位医生的习惯偏好（常用诊断模板、常开处方、偏好报告格式），越用越懂你                   | 可基于现有 memory_config 扩展 |
| 6   | 拖拽式工作流编排√   | 医生可视化编排智能体工作流，像搭积木一样自定义"上传→OCR→判断类型→处理→保存→通知"的流程        | 前端工作量大                 |
