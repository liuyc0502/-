# 智能体配置

## Context

管理端已经有完整的智能体配置页面，支持创建 portal 主智能体和工具智能体，维护模型、提示词、工具集和子智能体关系。这是系统智能行为的核心配置入口。

**核心需求：** 提供一个可视化的智能体编排面板。

------

## Architecture

```
智能体配置页 →
创建/编辑 agent →
配置模型、最大步数、提示词 →
选择工具 →
选择子智能体 →
导入/导出/删除
```

核心表：

- `ag_tenant_agent_t`
- `ag_tool_info_t`
- `ag_tool_instance_t`
- `ag_agent_relation_t`

------

## Implementation Steps

### Phase 1: 智能体 CRUD 与关系管理接口

后端 `/opt/backend/apps/agent_app.py` 提供：

- 运行
- 更新
- 删除
- 导入
- 导出
- 列表
- 创建中子智能体 ID
- 关联/移除子智能体
- 调用关系查询

### Phase 2: 配置编排页

前端核心组件：

- `/opt/frontend/app/[locale]/setup/agents/components/AgentSetupOrchestrator.tsx`
- `SubAgentPool.tsx`
- `CollaborativeAgentDisplay.tsx`
- `ToolPool.tsx`
- `PromptManager.tsx`

### Phase 3: 配置内容

可维护项包括：

- 名称、展示名、描述、分类
- 端口角色类型
- 主模型与步数
- duty / constraint / few shots prompt
- 可用工具
- 子智能体调用关系

------
