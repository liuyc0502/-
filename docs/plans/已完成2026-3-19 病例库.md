# 病例库

## Context

医生端已经有一套完整的病例库功能，不只是查看历史病例，还支持创建、编辑、搜索、收藏和最近浏览，能够沉淀成长期复用的临床案例资产。

**核心需求：** 提供结构化病例仓，服务于病例检索、教学复盘和讨论。

------

## Architecture

```
病例库 →
检索 / 收藏 / 最近浏览 →
进入病例详情 →
编辑症状 / 检验结果 / 图像 / 详细病史 →
沉淀为结构化案例资产
```

核心表：

- `medical_case_t`
- `medical_case_detail_t`
- `medical_case_symptom_t`
- `medical_case_lab_result_t`
- `medical_case_image_t`
- `medical_case_favorite_t`
- `medical_case_view_history_t`

------

## Implementation Steps

### Phase 1: 病例库接口

后端 `/opt/backend/apps/medical_case_app.py` 提供：

- 创建病例
- 列表检索
- 自然语言搜索
- 按 ID / 病例号查询
- 更新和删除
- 收藏切换
- 收藏列表
- 最近浏览
- 详情写入
- 图片、症状、检验结果增删

### Phase 2: 病例库列表页

前端 `/opt/frontend/components/doctor/cases/CaseLibraryView.tsx` 提供：

- 病例检索
- 我的收藏
- 最近浏览
- 高级筛选
- 新建病例

### Phase 3: 病例详情页

前端 `/opt/frontend/components/doctor/cases/CaseDetailView.tsx` 提供：

- 基础信息编辑
- 详细病史
- 关键症状
- 检验结果
- 医学图像
- 操作区和统计区
