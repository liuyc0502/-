# 康复计划双端协同

## Context

当前系统已经具备“医生制定康复计划，患者每日执行并反馈完成度”的双端协同能力。这是患者端最明确的持续性功能之一。

**核心需求：** 医生端负责制定计划，患者端负责执行计划，系统自动记录完成情况并生成进度统计。

------

## Architecture

```
医生端：
创建康复计划 →
添加用药 / 任务 / 注意事项 →

患者端：
查看今日计划 →
勾选用药和任务完成情况 →
系统写入 completion →
生成周完成度统计
```

核心表：

- `care_plan_t`
- `care_plan_medication_t`
- `care_plan_task_t`
- `care_plan_precaution_t`
- `care_plan_completion_t`

------

## Implementation Steps

### Phase 1: 康复计划接口

后端 `/opt/backend/apps/care_plan_app.py` 提供：

- 创建、查询、更新、删除计划
- 增删用药
- 增删任务
- 增删注意事项
- 记录完成情况
- 查询今日计划
- 查询周进度
- 从医嘱生成计划

### Phase 2: 医生端计划管理

前端医生端组件：

- `/opt/frontend/components/doctor/patients/PatientCarePlans.tsx`
- `/opt/frontend/components/doctor/patients/CreateCarePlanModal.tsx`
- `/opt/frontend/components/doctor/patients/CarePlanCompletionStats.tsx`

### Phase 3: 患者端执行页

前端患者端 `/opt/frontend/components/patient/care-plan/CarePlanView.tsx` 提供：

- 今日用药提醒
- 今日康复任务
- 注意事项
- 周进度统计
- 勾选完成并回写
