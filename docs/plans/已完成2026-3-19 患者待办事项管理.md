# 患者待办事项管理

## Context

医生端已经支持为患者创建待办事项，用于复查、用药、检查、随访等后续动作管理。它承接的是“诊疗结束后仍需跟进”的那部分工作。

**核心需求：** 将患者后续动作从聊天或纸面提醒变为结构化待办。

------

## Architecture

```
患者详情 →
待办事项 Tab →
创建待办 →
更新完成状态 / 删除 →
按待办、已完成、逾期分组展示
```

核心表：

- `patient_todo_t`

------

## Implementation Steps

### Phase 1: 待办接口

后端 `/opt/backend/apps/patient_app.py` 提供：

- 创建待办
- 查询患者待办列表
- 更新待办状态
- 删除待办

### Phase 2: 医生端待办页

前端 `/opt/frontend/components/doctor/patients/PatientTodos.tsx` 负责：

- 列表加载
- 按状态分组
- 逾期标记
- 编辑状态
- 删除待办

### Phase 3: 创建弹窗

前端 `/opt/frontend/components/doctor/patients/CreateTodoModal.tsx` 负责录入：

- 标题
- 描述
- 类型
- 截止日期
- 优先级

------
