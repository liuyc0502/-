# 医生端患者档案管理

## Context

医生端已经具备完整的患者档案管理入口，包括创建患者、检索患者、查看基本资料、编辑资料和删除患者。它是后续时间线、待办、报告、康复计划的业务起点。

**核心需求：** 提供一个以患者为中心的主档案管理页面。

------

## Architecture

```
患者列表 →
搜索 / 筛选 / 创建 →
进入患者详情 →
查看并编辑基础信息
```

核心表：

- `patient_info_t`

------

## Implementation Steps

### Phase 1: 患者 CRUD 接口

后端 `/opt/backend/apps/patient_app.py` 提供：

- 创建患者
- 查询患者详情
- 患者列表检索
- 更新患者
- 删除患者
- 按邮箱查询患者档案

### Phase 2: 患者列表页

前端 `/opt/frontend/components/doctor/patients/PatientListView.tsx` 提供：

- 搜索姓名/病历号/诊断
- 按全部、近期就诊、待随访、疑难病例筛选
- 新建患者
- 删除患者

### Phase 3: 患者概览页

前端 `/opt/frontend/components/doctor/patients/PatientOverview.tsx` 提供：

- 基础信息展示
- 常用字段原地编辑
- 最近动态
- 与患者相关对话入口

------
