# 诊疗时间线管理

## Context

患者档案的核心不是静态字段，而是诊疗过程。当前系统已经支持按阶段记录患者时间线，并为每个阶段挂接详情、病理发现、图片、附件和指标。

**核心需求：** 构建“患者诊疗主线”，让医生可以按阶段维护完整病程。

------

## Architecture

```
患者详情 →
新建时间线阶段 →
查看阶段详情 →
编辑 detail / 图片 / 附件 / 指标 →
形成完整病程时间轴
```

核心表：

- `patient_timeline_t`
- `patient_timeline_detail_t`
- `patient_medical_image_t`
- `patient_metrics_t`
- `patient_attachment_t`

------

## Implementation Steps

### Phase 1: 时间线接口

后端 `/opt/backend/apps/patient_app.py` 提供：

- 创建时间线阶段
- 查询患者全部时间线
- 查询单个时间线详情
- 保存 detail
- 删除时间线阶段
- 创建/删除时间线图片
- 批量创建/删除指标
- 创建/删除附件

### Phase 2: 医生端时间线主视图

前端 `/opt/frontend/components/doctor/patients/PatientTimeline.tsx` 负责：

- 时间轴展示
- 阶段详情展开
- 阶段状态和进度感知
- 跳转相关对话

### Phase 3: 编辑与补充组件

前端配套组件：

- `CreateTimelineModal.tsx`
- `EditTimelineDetailModal.tsx`

医生可在其中维护：

- 医生备注
- 病理发现
- 用药方案
- 患者总结
- 患者建议
- 阶段图片和文件
