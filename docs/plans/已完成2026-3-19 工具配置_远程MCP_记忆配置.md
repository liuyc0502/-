# 工具配置 + 远程 MCP + 记忆配置

## Context

除了主业务功能，系统还已经具备一组直接影响智能体运行效果的配置能力：

- 工具配置
- 远程 MCP 接入
- 记忆配置与记忆条目管理

它们决定智能体能调什么工具、能接什么外部能力、是否保留长期记忆。

**核心需求：** 为智能体提供运行时增强能力，而不是只配置 prompt 和模型。

------

## Architecture

```
工具配置 →
启用/校验工具参数

远程 MCP →
注册 MCP server →
探测远程工具 →
健康检查

记忆配置 →
设置记忆策略 →
新增/搜索/清理记忆
```

核心表：

- `ag_tool_info_t`
- `ag_tool_instance_t`
- `mcp_record_t`
- `memory_user_config_t`

------

## Implementation Steps

### Phase 1: 工具配置

后端 `/opt/backend/apps/tool_config_app.py` 提供：

- 工具列表
- 搜索
- 更新
- 扫描工具
- 加载配置
- 校验配置

### Phase 2: 远程 MCP 接入

后端 `/opt/backend/apps/remote_mcp_app.py` 提供：

- 远程工具发现
- 添加 MCP server
- 删除 MCP server
- 列表
- 健康检查

### Phase 3: 记忆配置

后端 `/opt/backend/apps/memory_config_app.py` 提供：

- 加载/设置记忆配置
- 屏蔽 agent
- 新增记忆
- 搜索记忆
- 列表
- 删除
- 清空

这些能力最终都会反映到智能体的实际调用边界和行为稳定性上。
