# 医生端知识库与学习记录

## Context

医生端已经有独立的知识库页面，可浏览知识分类树、读取文件内容、查看知识卡片，并自动记录学习行为。它服务于问答前准备和日常知识沉淀。

**核心需求：** 把知识资料浏览从“文件堆”变成“可阅读、可记录、可统计”的知识工作台。

------

## Architecture

```
知识库页面 →
加载知识库列表 →
展开文件树 →
读取文件内容 →
按分类查看知识卡片 →
写入学习记录并展示统计
```

核心表：

- `knowledge_record_t`
- `knowledge_file_card_t`
- `doctor_learning_record_t`

------

## Implementation Steps

### Phase 1: 知识库接口

后端 `/opt/backend/apps/doctor_knowledge_app.py` 提供：

- 列出知识库
- 列出知识库文件
- 读取文件内容
- 保存知识卡片
- 查询单个知识卡片
- 查询全部知识卡片
- 删除知识卡片

### Phase 2: 学习记录接口

后端 `/opt/backend/apps/learning_record_app.py` 提供：

- 记录浏览
- 查询学习记录
- 查询学习统计
- 删除单条
- 清空全部

### Phase 3: 医生端页面

前端 `/opt/frontend/components/doctor/knowledge/KnowledgeBaseView.tsx` 提供：

- 知识检索 Tab
- 学习记录 Tab
- 分类树浏览
- Markdown 文件阅读
- 学习统计面板

------
