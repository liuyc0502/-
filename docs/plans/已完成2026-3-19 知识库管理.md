# 知识库管理

## Context

系统的知识库并不是前端写死内容，而是后台可配置的检索库。当前已支持索引管理、文档上传、文件处理、摘要生成和租户级知识库选择。

**核心需求：** 提供从“上传文档”到“可被智能体检索”的知识库管理链路。

------

## Architecture

```
知识库管理页 →
创建索引 →
上传文档 →
处理文件 →
生成摘要 →
保存租户知识列表 →
供问答智能体检索
```

核心表：

- `knowledge_record_t`
- `tenant_config_t`

------

## Implementation Steps

### Phase 1: 索引与文件接口

后端：

- `/opt/backend/apps/elasticsearch_app.py`
- `/opt/backend/apps/file_management_app.py`
- `/opt/backend/apps/knowledge_summary_app.py`
- `/opt/backend/apps/tenant_config_app.py`

### Phase 2: setup 页面

前端 `/opt/frontend/app/[locale]/setup/knowledges/page.tsx` 负责：

- 进入知识库配置流程
- 加载配置
- 刷新知识库数据
- 保存后进入智能体配置或直接进入聊天

### Phase 3: 业务作用

知识库管理决定：

- 哪些文档进入检索系统
- 哪些知识库对当前租户生效
- 智能体回答可引用哪些本地知识来源

------
